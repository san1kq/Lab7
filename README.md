### Описание
Программа на языке C, демонстрирующая использование оператора множественного выбора `switch`:

* **Задание 1:** распознавание введённого символа с помощью `switch` (цифра, буква или другой символ).
* **Задание 2:** программа «Калькулятор» (сложение, вычитание, умножение, деление), ввод в формате `scanf("%f%c%f", &x, &c, &y)`, дополнительный функционал: возведение в степень и проверка деления на ноль.
* **Домашнее задание:** определение знака Зодиака по дате, введённой одним числом `ddmm`, без использования `if-else`.
